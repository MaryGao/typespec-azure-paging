# MissingDefaultResponse and RequiredDefaultResponse migration

## 1. Conclusion and scope

The TypeSpec rule `@azure-tools/typespec-azure-resource-manager/require-standard-error-response` implements the shared ARM generic error-response policy of [MissingDefaultResponse](https://github.com/Azure/azure-openapi-validator/blob/e1b8b207a196cf2fc288593efec22e6e38ab98d5/docs/missing-default-response.md) and [RequiredDefaultResponse](https://github.com/Azure/azure-openapi-validator/blob/e1b8b207a196cf2fc288593efec22e6e38ab98d5/docs/required-default-response.md). **The intended response-presence policy is covered, but raw diagnostics and source populations are not equivalent.** Native intentionally avoids the Spectral response-key selector bug that misses absent generic error responses, and also checks non-service SDK customization/compatibility declarations absent from saved Swagger. Whether those declarations belong in the policy remains a rollout decision; recommended activation stays disabled.

The check requires a response covering otherwise undeclared status codes, not a particular payload or error marker. It covers concrete operations across HTTP methods, including HEAD. `MissingXmsErrorResponse` is not part of this migration.

## 2. Actual coverage

All 487 frozen projects were assessed without a project filter or limit, with no compile/worker failures or unassessed projects in that population. Reported diagnostics are individual findings, not project counts. Swagger totals are saved successful production observations: zero `MissingDefaultResponse` plus 178 `RequiredDefaultResponse`. TypeSpec totals are fresh target-only source diagnostics from one shared rule, not summed twice across the Swagger members.

The [complete 487-project inventory](validation/full/projects.md) records every project, saved API version, both Swagger counts, native count, matched count and raw native receipt, including all zero-finding projects. The [full-corpus report](validation/full/README.md) provides the execution and per-operation evidence.

**Assessed coverage:** all 178 historical `RequiredDefaultResponse` findings have mutual one-to-one native witnesses, with zero Swagger-only or ambiguous findings. These also corroborate 178 emitted-operation false negatives of `MissingDefaultResponse`. The additional 308 native findings are verified non-service source declarations without saved Swagger counterparts, not additional saved-wire defects. All 24 finding projects and the 463 zero-finding projects are accounted for in the complete inventory. The matched-operation row counts the verified common subset; it does not normalize the 486 raw native findings or establish source-population equivalence. Default activation, fresh emission and selected-version projection remain unassessed.

## 4. Why diagnostic counts differ

The full-corpus differences are measured separately for each Swagger member. Swagger counts are raw saved diagnostics; TypeSpec counts include only the archived candidate's `missing-default-response` warning, now named `require-standard-error-response`, not unrelated warnings. The shared native count is not summed across members.

| Difference (with evidence)                                                                                      | Swagger diagnostics                    | TypeSpec diagnostics for the same check | Recommended action and rationale                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------- | -------------------------------------- | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Spectral selector defect](members/MissingDefaultResponse/migration.md)                                         | 0                                      | 486                                     | Decompose the excess: 178 corroborated saved-wire false negatives plus 308 non-service source declarations. Do not label all 486 Spectral false negatives. |
| [Legacy response-map check](members/RequiredDefaultResponse/migration.md)                                       | 178                                    | 486                                     | All 178 captured, zero Swagger-only; 308 native-only non-service declarations. Raw counts differ because source populations differ.                        |
